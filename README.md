# 🏦 Fraud Detection System

A comprehensive banking transaction fraud detection system with C backend and web interface.

## 🌟 Features

- **Real-time Fraud Detection**
  - High-value transaction monitoring (> ₹50,000)
  - Rapid multiple transaction detection (≥3 in 60 seconds)
  - Impossible travel detection (different locations in 10 minutes)
- **Web Interface** - Modern, responsive UI
- **REST API** - JSON-based communication
- **Sample Data** - Pre-configured test scenarios

## 🛠 Tech Stack

- **Backend**: C (Fraud detection logic)
- **Frontend**: HTML5, CSS3, JavaScript
- **Server**: Node.js + Express
- **Communication**: REST API, JSON
